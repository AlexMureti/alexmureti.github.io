# Alex Maingi — portfolio

[alexmureti.github.io](https://alexmureti.github.io). One HTML file, Inter from Google Fonts, no build step.

- `index.html` — the site.
- `media/` — project thumbnails (real screenshots), six-second film teasers and posters, the share image.
- `status.json` — written every morning by `.github/workflows/status.yml`, which checks each site in `systems.txt`. The page reads it to colour the status dots.
- `Alex-Maingi-Profile.pdf` — the one-page profile.
- `archive/` — earlier versions.

Full films are release assets, not tracked files.
