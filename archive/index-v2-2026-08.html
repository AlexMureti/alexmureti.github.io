001
Fintech · Machine learning

Credit Scoring Engine

A scoring service for a licensed Kenyan lender. It ingests applicant and bureau data, returns a decision, and runs as a containerised API on a VPS that a partner bank posts to in production. Includes an isolated agriculture-finance pipeline scored on separate criteria from consumer lending, because a farmer's cash flow is seasonal and a salaried borrower's is not.

002
Fintech · Lending

Brisk Credit

Production site for a Kenyan microlender. Product-aware repayment calculator, phone-OTP accounts, and an application form that writes directly into the client's existing loan-management system across 42 branches — with email, WhatsApp and form fallbacks so a lead is never lost if the write fails. Built for mama-mboga borrowers, in English and light Swahili.

003
Hospitality · Direct booking

Kito Oak Haven

A direct-booking site built to take a Nairobi apartment off platform fees. The centrepiece is a calculator the guest drives: they enter the quote Airbnb gave them, see the direct price, and the WhatsApp message arrives pre-filled with those figures. The walkthrough is eight distinct scroll mechanics — pinned, scrubbed, split, still — so it never reads as a photo album. Desktop gets a silent hero film cut from a 30-megapixel shoot; phones never download it.
